# 留言板

书最后有几页留言板。这里放的是已经排进书里的留言。

## 怎么留一条

1. 打开仓库根目录的 [`messages.tex`](../messages.tex)
2. 在最后一行之前，加一行：

   \`\\boardentry{署名}{2026-11}{一句话，60 字以内}\`

   - 署名可以写真名、昵称，也可以写「一位大二读者」或直接匿名
   - 时间写 `YYYY-MM`
   - 留言 60 字以内，一句话说清
3. 发 PR，标题写 `board: 你的署名`

## 写什么

- 一句给后来者的话：你踩过的坑、你希望有人早点告诉你的事
- 一句对这本书的批评或建议（越具体越好）
- 一句谢谢，或一句反驳

## 不写什么

- 广告、课程、社群引流
- 人身攻击、学历/地域歧视
- 涉及他人隐私或未经同意的内容
- 超过 60 字的长文（长文请开 Issue，不要放留言板）

## 排版说明

留言按提交顺序排，每条之间有一条细线；纸书读者可以在最后的横线上手写。合并后书会重新编译，留言进入下一版 PDF 和 Releases。
