# 留言板

书最后一页是留言板，做成弹幕的样子：每条位置、字号、颜色、字体、角度都可以不一样。

## 怎么留一条

打开仓库根目录的 `messages.tex`，在末尾加一行：

```latex
\boardentry[color=orange!85!black, size=11pt, font=\itshape, indent=1.2cm, rotate=1, gap=0.2cm]{你的署名}{2026-11}{一句话，60 字以内。}
```

方括号里的参数都可以省略，随便调：

| 参数 | 作用 | 取值 |
|---|---|---|
| `color` | 文字颜色 | `teal`、`ink`、`orange!85!black`、`teal!70!black` 等 |
| `size` | 字号 | `9pt` 到 `14pt` |
| `font` | 字重 / 字宽 | `\bfseries`（加粗）、`\itshape`（倾斜） |
| `indent` | 左侧缩进 | `0cm` 到 `3cm` |
| `rotate` | 倾斜角度 | `-3` 到 `3` |
| `gap` | 与上一条的距离 | `0cm` 到 `1cm` |

## 写什么

- 一句给后来者的话：你踩过的坑、希望有人早点告诉你的事
- 一句对这本书的批评或建议（越具体越好）
- 一句谢谢，或一句反驳

## 不写什么

- 广告、课程、社群引流
- 人身攻击、学历/地域歧视
- 涉及他人隐私或未经同意的内容
- 超过 60 字的长文（长文请开 Issue）

## 排版说明

留言按提交顺序排，合并后书会重新编译，你的话会进入下一版 PDF 和 Releases。纸书读者可以在页面下方的虚线框里手写。
