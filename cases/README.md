# cases/ 真实案例

收的是**具体发生过的事**：谁、在什么约束下、做了什么、结果如何、复盘出什么。

## 一个可用的结构

```markdown
# 标题：一句话说清楚这段经历证明了什么
（例：双非本科生，用本地企业的报修系统过了中厂简历关）

## 背景
学校 / 年级 / 专业 / 当时的资源限制

## 我做了什么
具体动作、时间投入、遇到的卡点

## 结果
可验证的部分：上线、用户数、面试通过 / 被拒、复盘结论

## 如果重来
下一次会怎么改
```

## 硬性要求

- 脱敏：隐去姓名、公司、可识别的项目细节
- 有结果：哪怕是「失败了，原因是 X」也比「收获很大」有用
- 不接受：编造、软文、培训广告

## 命名

`cases/2026-11-双非-本地企业跳板.md`（时间-关键词.md）
